# Official logo

`logo.webp` is the VKS Film Productions logo used in the header, mobile menu and footer by `BrandLogo.jsx`.
It was cut from `public/logo/android-chrome-512x512.png` (round badge, white corners made transparent).

To replace it, drop a new file here named `logo.svg` (preferred), `logo.png`, `logo.webp`, `logo.avif` or `logo.jpg`
(keep only one) and update the `width`/`height` attributes in `BrandLogo.jsx` to match its size.

PNG favicons, the Apple touch icon, Android icons and the web manifest live in `public/logo/`.
`public/favicon.ico` and `public/apple-touch-icon.png` are root copies that browsers request automatically;
update them together with the files in `public/logo/`.
